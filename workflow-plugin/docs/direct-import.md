# 扁平 Fusion 字幕导入、长任务进度与连接符

## 片段结构

### 散落

时间线每行歌词是一个**顶层直接包含标题节点的 Fusion 文字片段**：每个片段保留一个活动 Fusion 合成，包含现有 `AppleMusicStyleTitle` 宏，不再以 MediaIn 引用一层内部歌词片段。

编辑时选中时间线上的歌词片段，切换到 Fusion 页面即可编辑本句的文字节点；不需要进入逐句内层时间线。各句合成独立，修改一行不会串改另一行。

**类型边界：** 这些项目的容器仍是 Fusion 片段，不是 `InsertFusionTitleIntoTimeline` 直接产生的效果库标题类型。原生插入 API 不提供可靠的目标轨道参数；锁住默认轨道不会自动选择新轨道。为保证精确位置、时长和不覆盖已有剪辑，插件采用一份共享空白定位源批量 Append，然后把标题图直接导入各实例顶层。

每次导入只创建一份定位源并导出一次模板，不再每句 `CreateFusionClip`。媒体池“AppleMusic样式标题生成”中会保留这份共享源；其内部是空白占位，不是编辑歌词的位置，也不要在仍有引用时删除。

### 合并

先生成上述扁平文字片段，再调用一次 `CreateCompoundClip`。

结构为：

```text
一个外层复合片段
  ├─ 第一句：顶层 Fusion 文字
  ├─ 第二句：顶层 Fusion 文字
  └─ 第三句：顶层 Fusion 文字
```

不再是“汇总 Fusion 片段 → 每句 Fusion 包装 → 原始标题”。UI 文案改为“合并为一个复合片段”；任务字段仍保留 `placementMode: "fusion-clip"` 以读取已有配置，但此选项现在对应外层复合片段。

原有项目不会被迁移、拆解或覆盖；新结构只对更新后重新导入的歌词生效。

## 长任务

- 读取连接状态仍有普通请求超时。
- **render 不再使用固定 120 秒空闲截止时间。** 关闭请求连接不能取消 Resolve 内部写入，因此不能把等待过久等同于导入失败。
- Python 在同一线程串行调用 Resolve API；仅网络心跳使用辅助线程。
- render 响应为 `application/x-ndjson`：进度帧、5 秒间隔心跳，最后恰好一个 `{ok,data}` 或 `{ok:false,error}` 结果。
- Node 同时兼容旧宿主的单 JSON 响应；收到进度或 HTTP 200 本身不会提前报告成功。
- 真正断线且没有最终结果时提示“结果不确定，任务可能仍在执行，请勿重复导入”；不会自动重发写请求。
- 进度回调或临时文件清理失败不会把已完成写入误判为失败。

## 分段连接符

在界面中选择：

- **自动**：英文分词之间补空格，中文不自动补；已有空白和分词 span 外的标点保留，英文单字母逐字段不被自动拆成带空格的字母串。
- **自定义**：在所有语言的已有分词／逐字段之间使用输入的连接符，例如空格、`·`、` / `；留空表示直接连接。

连接符附加到前一段文字，不创建额外时间段，原始 startMs/endMs 不变。原文不就地修改，切换设置不会累计插入多个连接符。

没有逐字分段的逐行歌词，只替换原有水平词间空白，保留换行；不会自动给连续中文猜分词，也不会伪造逐字时间。

限制：最多 32 个 Unicode 码点，不允许 `|`、换行或控制字符，因为 `|` 是当前标题的分段语法。加入连接符后的最终文字仍受 256 码点上限保护，在创建轨道前检查。

## 验证与边界

### 实际 Resolve 原生 API 验证

在独立 QA 工程验证了新路径所需的关键操作：

- 共享源的两个实例分别放到 V2 的 86424 / 86520 帧，长度为 72 / 48 帧。
- 每个实例导入标题图并删除旧合成后，合成数量为 1，存在顶层 AppleMusicStyleTitle，没有 MediaIn1。
- 修改第二句为 SECOND 后，第一句仍为 FIRST，合成互不串改。
- 两句可包为一个外层 Compound Clip，而不是再包一个汇总 Fusion 图。
- 测试前已保存并导出原工程备份，测试结束成功切回原工程。

### 回归测试

- Python：单一定位源、顶层合成、唯一外层复合片段、非法输入写入前拒绝、失败回滚、进度监听失效不取消写入。
- Python HTTP：真实 RpcHandler 的 NDJSON 进度与最终成功／失败帧。
- Node：两个桥接后端的结构、实际 HTTP 空闲超时缩短复现、流式进度、断线不自动重发、英文空格／自定义连接符／标点、预览保留选区、完成后忽略迟到进度。

完整新旧批量流程测速开始时 Resolve 已退出，因此本轮**没有可信的整体速度提升数字**，也没有完成新版整批端到端实机导入。已验证的是关键原生操作和自动回归，不能将模拟 SDK 测试冒充完整宿主验收。

本轮未修改标题渲染源码、生成器或安装的标题文件；工作区同时发生的其他字幕改动予以保留，不回滚。只更新插件，不重新构建或安装标题。
